# BrainOn | AI 엔지니어링 프로젝트

[← GitHub 프로필로 돌아가기](../README.md)

4인 팀에서 CT·MRI·MRA 의료영상의 병변 분석 결과를 서비스 화면까지 연결한 프로젝트입니다. 저는 **데이터 품질 검증, 분할 모델 실험·평가, 추론 API와 결과 연동**을 맡았습니다.

**기술:** Python, PyTorch, MONAI, nnU-Net, SegResNet · FastAPI, Django, Celery · GCS, MLflow

## 제가 한 일

- **데이터 검증:** 출처가 다른 CT와 마스크의 대응 관계, NIfTI 방향·간격·affine, 레이블 값을 확인했습니다. 전처리 뒤에도 이진 마스크와 병변 부피가 의도대로 유지되는지 검사했습니다.
- **모델 실험:** nnU-Net과 SegResNet의 입력을 각각 준비하고 손실 함수와 샘플링 설정을 바꿔 실험했습니다. 설정과 데이터 분할을 기록해 결과를 비교했습니다.
- **평가:** 평균 Dice뿐 아니라 병변 단위 Recall·Precision, 크기별 결과, 음성 영상의 오탐을 살펴 작은 병변의 누락 여부를 확인했습니다.
- **서비스 연결:** FastAPI의 추론 입력·출력과 모델 로딩 구조를 작업하고 Django·Celery 분석 요청, GCS 저장, 뷰어의 마스크·확률 맵·XAI 표시를 연결했습니다. MLflow 모델 메타데이터를 관리자 화면에서 조회·동기화하는 흐름도 구현했습니다.

## 대표 사례: CT 출혈 분할

기준 실험 **H-N00**(nnU-Net, Dice+CE)과 변형 실험 **H-N80**(Tversky+CE, α=0.3·β=0.7)을 비교하며 작은 출혈을 놓치는지와 오탐이 늘어나는지를 함께 확인했습니다. 두 실험은 학습 epoch 설정도 달라 점수 차이를 손실 함수만의 효과로 해석하지 않았습니다. 검증 데이터에서 정한 threshold를 테스트 결과에 맞춰 다시 조정하지 않는 기준을 사용했습니다.

서로 다른 시점의 수치를 섞은 ‘최고 성능’은 제시하지 않았습니다. 수치를 공개할 때는 모델 버전과 고정된 평가 데이터 범위를 함께 명시하겠습니다.
