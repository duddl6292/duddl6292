# BrainOn | AI 엔지니어링 프로젝트

[← GitHub 프로필로 돌아가기](../README.md)

4인 팀에서 CT·MRI·MRA 의료영상의 병변 분석 모델을 서비스 화면에 연동했습니다. 담당 범위는 **데이터 품질 검증, 분할 모델 실험·평가, 추론 API와 결과 연동**입니다.

**사용 기술:** Python, PyTorch, MONAI, nnU-Net, SegResNet · FastAPI, Django, Celery · GCS, MLflow

## 담당 역할

| 영역 | 수행 내용 |
| :--- | :--- |
| **데이터 품질** | 출처가 다른 CT·마스크의 대응 관계와 NIfTI 방향·간격·affine·레이블 검증. 전처리 후 이진 마스크와 병변 부피 점검 |
| **모델 실험** | nnU-Net·SegResNet별 입력 구성, 손실 함수와 샘플링 설정 실험. 설정 및 데이터 분할 기록 |
| **성능 평가** | Dice 외에 병변 단위 Recall·Precision, 크기별 결과와 음성 영상 오탐 분석 |
| **추론·서비스** | FastAPI 모델 로딩·추론 입출력 구성, Django·Celery 분석 요청과 GCS 저장 연동. 뷰어의 마스크·확률 맵·XAI 결과 연결 |
| **모델 관리** | MLflow 모델 메타데이터의 관리자 화면 조회·동기화 흐름 구현 |

## 대표 사례 | CT 출혈 분할

**문제:** 평균 Dice만으로는 작은 출혈의 누락이나 음성 영상의 오탐을 파악하기 어려웠습니다.

**접근:** nnU-Net 기준 실험 **H-N00**(Dice+CE)과 변형 실험 **H-N80**(Tversky+CE, α=0.3·β=0.7)을 비교하고, 병변 크기별 검출과 오탐을 함께 분석했습니다. 검증 데이터에서 정한 threshold는 테스트 결과에 맞춰 재조정하지 않는 기준을 적용했습니다.

**해석:** 두 실험의 학습 epoch 설정도 달라 성능 차이를 손실 함수만의 효과로 단정하지 않았습니다. 서로 다른 시점의 수치를 합쳐 ‘최고 성능’으로 제시하지 않았으며, 공개 수치에는 모델 버전과 고정된 평가 데이터 범위가 필요합니다.
