## 프로젝트 요약

| 항목 | 내용 |
| :--- | :--- |
| 프로젝트 | 뇌혈관질환 의료영상 AI와 임상 의사결정 지원 서비스 |
| 참여 | 4인 팀 프로젝트 |
| 분석 대상 | CT 뇌출혈, MRI 허혈성 병변(DWI·ADC), MRA 뇌동맥류 |
| 담당 영역 | 데이터 품질 검증, 모델 실험·평가, 추론 API, 분석 결과 연동 |
| 사용 기술 | Python, PyTorch, MONAI, nnU-Net, SegResNet, FastAPI, Django, Celery, GCS, MLflow |

의료영상의 병변 분할 결과를 의료진이 확인할 수 있도록 **데이터 검증 → 모델 실험 → 평가 → 추론 서비스 → 결과 화면**을 연결한 프로젝트입니다. 모델 개발과 CDSS 서비스 개발은 하나의 BrainOn 프로젝트 안에서 진행했습니다.

## 해결하려 한 문제

데이터셋마다 영상의 방향·간격과 레이블 형식이 달라 학습 전에 품질 확인과 입력 규격 정리가 필요했습니다. 병변 크기도 다양해 전체 평균 성능만 보면 작은 병변의 검출 실패를 놓칠 수 있습니다. 학습이 끝난 모델을 서비스에 적용할 때는 입력·출력 계약과 모델 버전을 분명히 해야 했습니다.

## 제가 맡은 작업

### 데이터 검증과 전처리

- CT 데이터의 방향, voxel spacing, affine 및 레이블 값을 점검하고 이진 출혈 마스크 기준을 정리했습니다.
- 데이터셋 간 형식 차이와 작은 병변 사례를 확인해 전처리 및 평가 과정에 반영했습니다.

### 모델 실험과 평가

- nnU-Net과 SegResNet을 바탕으로 손실 함수, 샘플링, 입력 구조를 비교했습니다.
- Dice, Recall, Precision과 병변 크기별 결과를 함께 살펴 실패 양상을 분석했습니다.
- 모델 선택을 단일 평균 점수로 단순화하지 않고 병변 검출과 오류 유형을 함께 검토했습니다.

### 추론 서비스와 결과 연동

- 영상 종류별 추론을 위한 공통 입출력 계약과 모델 로딩 구조를 작업했습니다.
- FastAPI 추론 API를 Django·Celery 분석 요청 및 GCS 저장 흐름에 연결했습니다.
- 의료진 뷰어에서 병변 마스크, 확률 맵, XAI 및 병변 정보를 조회할 수 있도록 결과 연동에 참여했습니다.
- MLflow Tracking·Registry의 모델 메타데이터를 관리자 화면에서 조회·동기화하는 흐름을 구현했습니다.

## 기술적 판단

| 관점 | 적용한 방식 |
| :--- | :--- |
| **데이터 신뢰성** | 영상 메타데이터와 레이블을 확인한 뒤 학습 입력을 구성 |
| **평가** | 평균 Dice 외에 Recall 및 작은 병변 결과를 함께 확인 |
| **재현성** | 실험 설정, 데이터 분할, 지표와 모델 버전을 구분해 관리 |
| **서비스 연결** | 모델 학습과 서비스 구현을 분리하고 추론 계약으로 연결 |
